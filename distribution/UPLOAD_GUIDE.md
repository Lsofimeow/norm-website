# 上传 NORM，让别人下载

固定公开下载页：
https://github.com/Lsofimeow/norm-website/releases/tag/windows-preview

1. 使用你的 GitHub 账号登录，打开上面的页面，点击铅笔图标 **Edit**。
2. 把实际可发布的 Windows 软件包命名为 **NORM-Windows-Preview.zip**，拖进 **Attach binaries** 区域，等上传完成。
3. 在发布说明中补充实际版本、使用说明、已知限制与校验值，点击 **Update release**。

官网的下载入口指向这个固定下载页。上传完成后，别人无需登录就能查看公开页面并下载该软件包。以后更新也使用同一个发布页面；保留文件名时，文件直链为：

https://github.com/Lsofimeow/norm-website/releases/download/windows-preview/NORM-Windows-Preview.zip

**这条文件直链只有对应附件上传后才有效。** 本轮只准备下载位置，没有收到或上传 NORM 安装包，也没有验证软件运行。GitHub 自动显示的 Source code 是网站源码，不能当作应用安装包。

你也可以把实际软件包发到本对话，再继续处理上传。上传软件包不要求重新发布官网，官网按钮始终指向同一个下载页。
